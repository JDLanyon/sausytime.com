## About The Project

![Project screenshot](full-tank-scene.png)

Being students ourselves — we’ve all got heaps to do, and procrastination is always a thing we struggle with.
Other to-do apps can be overly complex or feel like work, so we wanted something that makes you want to come back.
Our app aims to keep things simple but engaging by using timers, points, and a bit of gamification to help stay on top of tasks without feeling like a chore.
<sub><i>- Johann</i></sub>

### Core Features
- Pomodoro Study Timer
    - Customizable segment duration
    - Health reminders
    - Sound Effects
    - Earn points upon session completion
- Task Tracking
    - Add tasks
    - Delete tasks
    - Edit tasks
    - Mark tasks as priority & sort by high priority
    - Earn points upon task completion
- In-game store & Tank
    - Purchase fish for the tank
    - Purchase decorations for the tank
    - Animated fish & decorations


### Technical Features
- Local SQL database with password hashing
- DAO Factory Pattern to instantiate complex objects
- Singleton Methods to track singular instances (sqlite connection)
- Data Access Objects separates data handling and business logic
- Enumeration, interfaces, inheritance and polymorphism, OOP principles to ensure data is properly shared between classes and enables scalable and modular development


### Built With

Task Tank is primarily built using JavaFX, where the UI is promodominantly written in `.fxml` while backend is written in Java.

## Usage

Unfortunately there is not a working build for this project currently, details on setting up a development environment with IntelliJ is outlined below.

### Prerequisites

1. It is recommended to download [IntelliJ IDEA Community Edition](https://www.jetbrains.com/idea/download), this is the IDE of choice within our unit and is what was used by all team members during development.

2. This project is built using jdk-21, which can be downloaded [here](https://www.oracle.com/java/technologies/downloads/#java21).


### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/OvercaffeinatedCAB302/fish-tank.git
   ```

2. Open the `fish-tank` project in IntelliJ

3. Navigate to `src/main/java/org/overcaffeinated/tasktank/LoginApplication.java` and run the current file, you should be able to run the entrypoint;
``` java
  public static void main(String[] args) {
    launch();
  }
```

4. If you can't run from `LoginApplication.java` as the "Current File", you may have to make a new configuration.
- Create a new **Application** configuration
- Set the name to Task Tank (optional)
- Set Build and run to use java 21 at `LoginApplication`
- If `LoginApplication` isn't available, check the **Project Structure** within IntelliJ and that you have installed Java 21 correctly.
